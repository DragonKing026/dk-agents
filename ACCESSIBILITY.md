# Accessibility

DK Code is at an early stage and does not claim to meet a formal accessibility standard. This page says what is known
and how to tell us about barriers.

## Current state

- **Supported environment:** Linux desktop. So far it has only been run from source on Fedora.
- **Editor:** the tree is close to Code - OSS and keeps its accessibility features, such as keyboard navigation and
  screen reader support. They have not been tested separately in this fork.
- **Planned features:** the agent chat, task board and office tab do not exist yet, so nothing can be said about them.

## Goal

Everything needed for daily work should be usable with a keyboard and a screen reader and readable at larger text
sizes. The office tab is a pixel-art canvas, so everything it shows must also be available in other views.

## Reporting a barrier

Open an issue with the *Bug report* template and mention "accessibility" in the title. Describe what you tried to do,
what assistive technology you use (if any), and what got in the way.
